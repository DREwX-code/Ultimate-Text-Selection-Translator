## Step 3 — Start Translating

Select any text on a webpage and translate it instantly using either:

- **Your configured keyboard shortcut** (default: **Ctrl + L**)
- **The floating translation button** that appears next to selected text

The keyboard shortcut can be changed at any time from the script settings, and the floating translation button can also be enabled or disabled globally or on a per-site basis.

## Updating

Most userscript managers automatically check for script updates.

You can also manually check for updates from your userscript manager dashboard.
