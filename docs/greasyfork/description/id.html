Ultimate Text Selection Translator

Sebuah alat yang sangat praktis yang memungkinkan kamu menerjemahkan teks apa pun yang diseleksi di halaman web secara instan menggunakan pintasan Ctrl+L.

Tidak perlu lagi menyalin dan menempel ke penerjemah eksternal — semuanya terjadi langsung di browser kamu.

Penerjemahan

  • Mendeteksi bahasa teks yang dipilih secara otomatis.
  • Menerjemahkan ke bahasa default browser kamu.

Opsi

  • Dengarkan hasil terjemahan dengan text-to-speech bawaan.
  • Salin terjemahan dengan satu klik.

Kinerja

  • Bekerja di semua situs tanpa konfigurasi apa pun.
  • Sangat cepat dan tidak memperlambat penjelajahan.
  • Dirancang untuk menghemat waktu dan meningkatkan produktivitas.
