Ultimate Text Selection Translator

Ένα εξαιρετικά πρακτικό εργαλείο που σου επιτρέπει να μεταφράζεις άμεσα κάθε επιλεγμένο κείμενο σε μια ιστοσελίδα, με τη συντόμευση Ctrl+L.

Τέλος στην αντιγραφή-επικόλληση σε εξωτερικούς μεταφραστές— όλα γίνονται απευθείας στον browser σου.

Μετάφραση

  • Ανιχνεύει αυτόματα τη γλώσσα του επιλεγμένου κειμένου.
  • Μεταφράζει στη προεπιλεγμένη γλώσσα του browser σου.

Επιλογές

  • Αναπαραγωγή της μετάφρασης μέσω text-to-speech.
  • Αντιγραφή της μετάφρασης με ένα κλικ.

Απόδοση

  • Λειτουργεί σε όλα τα sites χωρίς ρυθμίσεις.
  • Πολύ γρήγορο χωρίς να επιβαρύνει την περιήγησή σου.
  • Σχεδιασμένο για να αυξάνει την παραγωγικότητά σου.
