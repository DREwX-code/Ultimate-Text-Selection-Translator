Ultimate Text Selection Translator

A high-performance tool that allows you to instantly translate any selected text on a web page. No more copy-pasting into external translators. Everything happens directly inside your browser.

Translation

  • Automatically detects the language of the selected text.
  • Instant translation to your browser’s default language or the one selected in settings.
  • Smart action button that appears automatically after text selection for one-click translation.

Text-to-Speech (TTS)

  • Integrated audio playback for translated text.
  • Stable and consistent voice output.
  • Instant stop control with a single click.

Themes

  • Blue
  • Dark
  • Light
  • Global theme system applied across all panels.

Customization

  • Enable or disable the selection button (globally or per site).
  • Built-in blacklist to exclude specific domains, editable in settings.

Performance

  • No configuration required.
  • Compatible with most modern websites.
  • Smooth loading animation.
  • Lightweight architecture optimized for productivity.

Shortcut

  • Ctrl + L → Instantly translate selected text.
