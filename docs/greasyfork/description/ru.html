Ultimate Text Selection Translator

Высокопроизводительный инструмент, позволяющий мгновенно переводить любой выделенный текст на веб-странице. Больше не нужно копировать и вставлять текст во внешние переводчики. Всё происходит прямо в вашем браузере.

Перевод

  • Автоматически определяет язык выделенного текста.
  • Мгновенный перевод на язык браузера по умолчанию или выбранный в настройках.
  • Умная кнопка появляется автоматически после выделения текста для перевода в один клик.

Синтез речи (TTS)

  • Встроенное воспроизведение аудио переведённого текста.
  • Стабильное и чёткое звучание голоса.
  • Мгновенная остановка одним нажатием.

Темы

  • Синяя
  • Тёмная
  • Светлая
  • Глобальная система тем для всех панелей.

Настройка

  • Включение или отключение кнопки выделения (глобально или для отдельных сайтов).
  • Встроенный чёрный список для исключения доменов, редактируемый в настройках.

Производительность

  • Не требует настройки.
  • Совместим с большинством современных сайтов.
  • Плавная анимация загрузки.
  • Лёгкая архитектура, оптимизированная для продуктивности.

Горячая клавиша

  • Ctrl + L → Мгновенно переводит выделенный текст.
