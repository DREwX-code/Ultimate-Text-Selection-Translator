Ultimate Text Selection Translator

一款高效能工具，可即時翻譯網頁中選取的任何文字。 無需再複製貼上到外部翻譯器，所有操作皆可在瀏覽器內完成。

翻譯

  • 自動偵測所選文字的語言。
  • 即時翻譯為瀏覽器預設語言或設定中選擇的語言。
  • 選取文字後自動顯示智慧操作按鈕，一鍵即可翻譯。

文字轉語音 (TTS)

  • 內建翻譯文字的語音播放功能。
  • 穩定且清晰的語音輸出。
  • 單擊即可立即停止播放。

主題

  • 藍色
  • 深色
  • 淺色
  • 適用於所有面板的全域主題系統。

自訂

  • 啟用或停用文字選取按鈕（全域或依網站設定）。
  • 內建黑名單，可在設定中編輯以排除特定網域。

效能

  • 無需設定即可使用。
  • 相容於大多數現代網站。
  • 流暢的載入動畫。
  • 輕量化架構，專為提升效率而最佳化。

快捷鍵

  • Ctrl + L → 即時翻譯所選文字。
