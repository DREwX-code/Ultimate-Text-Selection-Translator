Ultimate Text Selection Translator

أداة عالية الأداء تتيح لك ترجمة أي نص محدد على صفحة الويب بشكل فوري. لم تعد بحاجة إلى النسخ واللصق في مترجمات خارجية، فكل شيء يتم مباشرة داخل متصفحك.

الترجمة

  • تكتشف لغة النص المحدد تلقائيًا.
  • ترجمة فورية إلى لغة المتصفح الافتراضية أو اللغة المختارة في الإعدادات.
  • زر ذكي يظهر تلقائيًا بعد تحديد النص لترجمته بنقرة واحدة.

تحويل النص إلى كلام (TTS)

  • تشغيل صوتي مدمج للنص المترجم.
  • صوت واضح ومستقر.
  • إيقاف فوري بنقرة واحدة.

السمات

  • أزرق
  • داكن
  • فاتح
  • نظام سمات شامل مطبق على جميع اللوحات.

التخصيص

  • تفعيل أو تعطيل زر التحديد (بشكل عام أو لكل موقع).
  • قائمة سوداء مدمجة لاستبعاد نطاقات محددة، قابلة للتعديل في الإعدادات.

الأداء

  • لا يتطلب أي إعداد.
  • متوافق مع معظم المواقع الحديثة.
  • رسوم تحميل سلسة.
  • بنية خفيفة محسّنة للإنتاجية.

الاختصار

  • Ctrl + L ← ترجمة فورية للنص المحدد.
