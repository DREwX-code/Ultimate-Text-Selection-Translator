מתרגם טקסט מיידי

כלי שימושי במיוחד שמאפשר לך לתרגם מיד כל טקסט מסומן בדף אינטרנט, בעזרת קיצור פשוט: Ctrl+L.

לא עוד העתק-הדבק למתרגמים חיצוניים — הכול מתבצע ישירות בתוך הדפדפן שלך.

תרגום

  • מזהה אוטומטית את שפת הטקסט המסומן.
  • מתרגם לשפת ברירת המחדל של הדפדפן שלך.

אפשרויות

  • האזן לטקסט המתורגם באמצעות מנוע הדיבור המובנה.
  • העתק את התרגום בלחיצה אחת.

ביצועים

  • עובד בכל האתרים ללא הגדרות נוספות.
  • מהיר במיוחד ואינו מאט את הגלישה.
  • נועד לחסוך זמן ולהעלות את הפרודוקטיביות שלך.
