Ultimate Text Selection Translator

Webページ上で選択したテキストを即座に翻訳できる高性能ツール。 外部翻訳サイトへコピー＆ペーストする必要はありません。すべてブラウザ内で完結します。

翻訳

  • 選択したテキストの言語を自動検出。
  • ブラウザの既定言語、または設定で選択した言語へ即時翻訳。
  • テキスト選択後にワンクリック翻訳が可能なスマートボタンを自動表示。

音声読み上げ (TTS)

  • 翻訳されたテキストの音声再生機能を内蔵。
  • 安定した自然な音声出力。
  • ワンクリックで即座に停止可能。

テーマ

  • ブルー
  • ダーク
  • ライト
  • すべてのパネルに適用されるグローバルテーマシステム。

カスタマイズ

  • 選択ボタンの有効化・無効化（全体またはサイト別）。
  • 特定ドメインを除外できる内蔵ブラックリスト（設定で編集可能）。

パフォーマンス

  • 設定不要ですぐに使用可能。
  • ほとんどの最新Webサイトに対応。
  • スムーズな読み込みアニメーション。
  • 生産性向上のために最適化された軽量設計。

ショートカット

  • Ctrl + L → 選択したテキストを即座に翻訳。
