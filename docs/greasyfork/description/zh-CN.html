Ultimate Text Selection Translator

一款高性能工具，可即时翻译网页中选中的任何文本。 无需再复制粘贴到外部翻译器，所有操作都在浏览器内完成。

翻译

  • 自动识别所选文本的语言。
  • 即时翻译为浏览器默认语言或在设置中选择的语言。
  • 选中文本后自动显示智能操作按钮，一键即可翻译。

文本转语音 (TTS)

  • 内置翻译文本的语音播放功能。
  • 稳定且清晰的语音输出。
  • 单击即可立即停止播放。

主题

  • 蓝色
  • 深色
  • 浅色
  • 适用于所有面板的全局主题系统。

自定义

  • 启用或禁用文本选择按钮（全局或按网站设置）。
  • 内置黑名单，可在设置中编辑以排除特定域名。

性能

  • 无需配置即可使用。
  • 兼容大多数现代网站。
  • 流畅的加载动画。
  • 轻量级架构，专为提升效率而优化。

快捷键

  • Ctrl + L → 即时翻译所选文本。
