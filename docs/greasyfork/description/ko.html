Ultimate Text Selection Translator

웹페이지에서 선택한 텍스트를 Ctrl+L 단축키로 즉시 번역할 수 있는 매우 편리한 도구입니다.

외부 번역기에 복사·붙여넣기할 필요가 없습니다 — 모든 작업이 브라우저 안에서 이루어집니다.

번역

  • 선택한 텍스트의 언어를 자동으로 감지합니다.
  • 브라우저 기본 언어로 번역합니다.

옵션

  • 내장된 음성 합성 기능으로 번역 내용을 들을 수 있습니다.
  • 번역을 한 번의 클릭으로 복사할 수 있습니다.

성능

  • 모든 사이트에서 설정 없이 작동합니다.
  • 매우 빠르며 브라우저 속도를 저하시키지 않습니다.
  • 시간 절약과 생산성 향상을 위해 설계되었습니다.
