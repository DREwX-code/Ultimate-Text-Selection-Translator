وەرگێڕەری دەقی دەستنیشانکراوی خێرا

ئامرازێکی زۆر کارەتەکانە کە ڕێگەت پێدەدات هەر دەقێک دەستنیشان بکەیت لەسەر پەڕەیەکدا بەخێرایی وەرگێڕی بکەیت، بە یەک کورتەکلیل: Ctrl+L.

دووربێ لە ڕاپچەکردن بۆ بەڕێوەبەرانی دەرەکی وەرگێڕان — هەموو شتێک لە ناو بەڕاوزەری خۆتدەروێت.

وەرگێڕان

  • زمانی دەقی دەستنیشانکراو بەخۆڕایی دیاریدەکات.
  • بە زمانێکی بنەڕەتی بەڕاوزەرەکەت وەرگێڕی دەکات.

هەڵبژاردنەکان

  • گوێگرتن بە وەرگێڕانەکە بە ڕابوونی دەنگ.
  • کۆپی کردنی وەرگێڕان بە یەک کلیک.

پێداهات

  • لەسەر هەموو ماڵپەڕەکان کاردەکات بێ پێوانەسازی.
  • زۆر خێرا و بێ ئەوەی وەستانی وێبگەڕکردنت.
  • دیزاین کراوە بۆ ئەوەی کاتت پاشەکەوت بکات و کاریگەری بەرز بکات.
