Ultimate Text Selection Translator

Uma ferramenta de alto desempenho que permite traduzir instantaneamente qualquer texto selecionado em uma página da web. Chega de copiar e colar em tradutores externos. Tudo acontece diretamente no seu navegador.

Tradução

  • Detecta automaticamente o idioma do texto selecionado.
  • Tradução imediata para o idioma padrão do navegador ou o idioma escolhido nas configurações.
  • Botão inteligente que aparece automaticamente após a seleção do texto para tradução com um clique.

Texto para Fala (TTS)

  • Reprodução de áudio integrada do texto traduzido.
  • Voz estável e clara.
  • Interrupção instantânea com um único clique.

Temas

  • Azul
  • Escuro
  • Claro
  • Sistema global de temas aplicado a todos os painéis.

Personalização

  • Ativar ou desativar o botão de seleção (globalmente ou por site).
  • Lista negra integrada para excluir domínios específicos, editável nas configurações.

Desempenho

  • Nenhuma configuração necessária.
  • Compatível com a maioria dos sites modernos.
  • Animação de carregamento suave.
  • Arquitetura leve otimizada para produtividade.

Atalho

  • Ctrl + L → Traduz instantaneamente o texto selecionado.
