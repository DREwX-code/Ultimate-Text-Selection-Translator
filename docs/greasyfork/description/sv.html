Ultimate Text Selection Translator

Ett mycket praktiskt verktyg som låter dig översätta markerad text direkt på en webbsida med genvägen Ctrl+L.

Ingen mer kopiering till externa översättare — allt sker direkt i din webbläsare.

Översättning

  • Identifierar automatiskt språket i den markerade texten.
  • Översätter till webbläsarens standardspråk.

Alternativ

  • Lyssna på översättningen via inbyggd talsyntes.
  • Kopiera översättningen med ett klick.

Prestanda

  • Fungerar på alla webbplatser utan inställningar.
  • Extremt snabbt utan fördröjning.
  • Utformat för att spara tid och öka produktiviteten.
